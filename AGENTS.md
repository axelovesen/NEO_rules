# Agent guidance

Read `README.md`, the applicable files in `.github/instructions/`, and the
relevant files in `rules/` before making a mapping decision.

- Treat the repository rules as authoritative only where they are marked
  normative.
- Do not create a dictionary of broker headers. Interpret source semantics from
  headers, nearby labels, values, formulas, worksheet context, and row context.
- Return an ambiguity instead of guessing.
- Preserve source traceability for every decision.
- Never modify the original broker workbook.
- Do not promote a `TODO` or `NEEDS_NEO_VALIDATION` statement to a business rule.
